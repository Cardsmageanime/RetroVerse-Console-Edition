# Platform requirements and authorization

Console Edition is a host application, not removable-media boot code.
- Desktop Linux: development/test platform; test existing UI and portable app components.
- PlayStation: requires Sony-approved SDK, signing and distribution permissions. External storage, emulation, chat and other capabilities subject to approval.
- Xbox: seek authorized retail application route; Developer Mode is not the target user experience. Do not treat developer mode as retail compatibility.
- Nintendo: requires authorized SDK and distribution, plus strict platform restrictions.
- No hacking, exploits, firmware modification, sideloading bypasses, or claims that console firmware updates will automatically keep unsupported apps running.
- Network transport is controlled by host OS; apps observe network availability and use permitted APIs. No direct Wi-Fi driver or Ethernet firmware modification.
- USB storage use is subject to console sandbox rules and user permissions. An official firmware-update USB file is not an app execution mechanism.
